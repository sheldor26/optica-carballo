# Template

Este archivo es un placeholder para verificar que el setup MDX funciona. Empieza con `_` así `listArticles()` lo excluye automáticamente.

## Estructura recomendada

1. **Intro** (50-80 palabras) — qué vas a aprender, por qué importa.
2. **Tabla de contenidos** — auto-generada desde headings H2.
3. **Cuerpo** — H2/H3 con código, ejemplos, callouts.
4. **CTA mid-article** — enlazar a herramienta IA o producto relacionado.
5. **FAQ** — preguntas frecuentes.
6. **Autor + revisor** — auto-rendered desde frontmatter.

## Sintaxis MDX

Podés usar **markdown estándar** + componentes React si los importás.

```ts
const ejemplo = 'código tipado';
```
